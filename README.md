# こころボール

見ることのできない自分の心をボールにして、客観的に眺め、触れて整えるためのWebアプリです。
スマホのホーム画面に追加すると、アプリのように全画面で使えます。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `three.min.js` | 3D表示のライブラリ（three.js r128、MITライセンス。`THREE-LICENSE.txt` 参照） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・全画面表示の設定 |
| `sw.js` | 電波がなくても開けるようにする仕組み |
| `icons/` | ホーム画面用のアイコン |

## 公開のしかた（GitHub Pages）

1. GitHubのリポジトリ `kokoro-ball` に、このフォルダの中身をそのまま置く
2. リポジトリの **Settings → Pages** を開く
3. **Build and deployment** の Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして **Save**
4. 1〜2分待つと `https://<ユーザー名>.github.io/kokoro-ball/` で開けるようになる

## iPhoneのホーム画面に追加する

1. **Safari** で上のURLを開く
2. 共有ボタン（四角から矢印）→「ホーム画面に追加」
3. 以後はホーム画面のアイコンから開く

## 記録の引っ越し

記録は、開いているブラウザ（またはホーム画面のアプリ）の中にだけ保存されます。場所が変わると記録は引き継がれないので、次の手順で移します。

1. 元の場所（claude.ai のこころボール）で「ふりかえり」→「控えを表示してコピー」
2. コピーした文字をメモアプリなどに貼って保存
3. 新しい場所（ホーム画面のこころボール）で「ふりかえり」→「控えから戻す」→ 貼り付けて「この内容で戻す」

※ Safariで開いたページと、ホーム画面に追加したアプリは、保存場所が別です。ふだん使うほう（ホーム画面）で戻してください。
※ なじみ・今週のボールの「整えたあと」は控えに含まれません（記録の点数・内容・ことばは含まれます）。

## 更新するとき

`index.html` などを直したら、`sw.js` の `VERSION` の数字を上げてから反映してください（例：`kokoro-ball-v1` → `kokoro-ball-v2`）。スマホ側では、アプリを一度閉じて開き直すと新しい版になります。

## 注意

- 見立ての点数は入力から計算した目安で、医学的な診断ではありません。
- 「傾けて転がす」は、iPhoneでは初回にボタンを押したとき許可を求められます（https で公開したページでのみ動きます）。
